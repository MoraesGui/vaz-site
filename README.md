# VAZ — Good News

Site estático da VAZ desenvolvido com HTML, CSS e JavaScript.

## Rodar localmente

Com Node.js instalado, execute na pasta do projeto:

```sh
node servir-previa.mjs
```

Abra http://127.0.0.1:8788/home.html e mantenha o terminal aberto. Não há dependências para instalar. Após editar e salvar os arquivos, atualize o navegador.

## Páginas

- `home.html`: início
- `boas-novas.html`: jornal
- `comunidade.html`: mural de recados salvo no navegador
- `colecao.html`: catálogo

Este repositório contém somente a versão estática. Os links de compra apontam para serviços externos; não inclui backend, processamento de pagamentos ou o tema Nuvemshop.

## Imagens e marca

Logos, fotografias e demais materiais de marca mantêm seus direitos originais. A visibilidade pública do repositório não concede licença de reutilização desses materiais. A origem e os termos da textura de papel estão em `assets/texturas/FONTES.md`.
